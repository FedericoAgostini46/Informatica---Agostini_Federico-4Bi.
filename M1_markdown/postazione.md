# MODULO M1 - ESERCIZI
## Esercizio 1 - Scheda personale di postazione

In questa prima sezione descriviamo le caratteristiche principali della nostra postazione di lavoro. La configurazione consente di svolgere in tranquillità tutte le attività del corso di informatica.

La postazione è situata nel laboratorio principale ed è assegnata al **PC Windows 11** che utilizziamo ogni settimana.

## Hardware

Il computer di postazione è equipaggiato con un processore Intel i7 di ultima generazione. Questa potenza di calcolo garantisce velocità ed efficienza durante l'esecuzione e la compilazione.

La memoria RAM disponibile è pari a 16 GB di memoria, sufficiente a gestire più macchine virtuali e ambienti di sviluppo contemporaneamente senza *rallentamenti* del sistema.

### Monitor e Periferiche

La postazione comprende un monitor da ventiquattro pollici con risoluzione alta per lavorare comodamente.

Sono presenti tastiera, mouse ergonomico e cavo di rete per il collegamento cablato.

## Software installato

Per la scrittura del codice utilizziamo l'editor **Visual Studio Code** versione 1.9x insieme alle sue estensioni principali. Per lo sviluppo in lingua Java è presente il JDK 17 configurato correttamente nelle variabili d'ambiente.

Per il controllo versione e la gestione del codice utilizziamo Git 2.4x installato in locale.

## Credenziali di accesso ai servizi del corso

Per accedere alla piattaforma per la consegna dei lavori utilizziamo l'account **GitHub** personale configurato nel corso delle prime lezioni.

Il laboratorio mette inoltre a disposizione un'istanza dedicata raggiungibile all'indirizzo del Jupyter server d'istituto per le esercitazioni di calcolo e analisi dati.
