# MODULO M1 - ESERCIZI
## Esercizio 2 - Istruzioni di compilazione con elenchi, comandi e citazioni

Per compilare ed eseguire il progetto Java presente nel repository appena clonato, seguire attentamente i passi descritti di seguito.

1. Aprire il terminale di comando e posizionarsi nella cartella radice del progetto clonato.
   * Verificare che la cartella `src/` contenga i sorgenti `.java`.
   * Assicurarsi che la cartella di destinazione `bin/` sia presente.
2. Compilare tutti i file sorgente presenti nella cartella `src/` salvando i file `.class` generati all'interno della cartella `bin/`.
3. Eseguire il comando di compilazione da terminale:

```bash
javac -d bin src/*.java
